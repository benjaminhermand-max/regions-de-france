# Régions de France

Application pédagogique pour les élèves de bac pro hôtellerie-restauration du lycée Ambroise Croizat (Moûtiers), tirée du cours « Les régions de France » de M. Hermand.

- Carte illustrée des 13 régions, dans l'ordre du cours
- Fiche par région : Identité, Spécialités, Fromages, Cave
- Glossaire filtrable (plats, fromages, boissons, région)
- Quiz par région ou toutes régions

Site statique, sans installation : il suffit d'ouvrir `index.html`. Hébergé sur GitHub Pages ; installable sur l'écran d'accueil du téléphone et consultable hors connexion.

Pour publier une mise à jour, augmenter `VERSION` dans `sw.js`.
